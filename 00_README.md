# Balíček pro projekty Claude a ChatGPT

Tento balíček obsahuje podklady pro založení dvou projektů:

1. Claude Project
2. ChatGPT Project

Součástí je také interaktivní dotazník `index.html` (17 otázek) pro sběr odpovědí od partnerů — nasazený na GitHub Pages.

## Doporučené použití

### Claude

- Název projektu: `Byznysový projekt – partnerský průsečík`
- Popis vložit ze souboru: `01_claude_project_description.txt`
- Project Instructions vložit ze souboru: `02_claude_project_instructions.md`
- Do Project Knowledge nahrát:
  - `05_znalostni_kontext_tymu.md`
  - `07_otazky_pro_partnery.md`
  - volitelně `06_startovaci_prompty.md`

### ChatGPT

- Název projektu: `Byznysový projekt – partnerský průsečík`

- Project Instructions vložit ze souboru: `04_chatgpt_project_instructions.md`
- Do souborů / znalostí projektu nahrát:
  - `05_znalostni_kontext_tymu.md`

  - volitelně `06_startovaci_prompty.md`

## Proč jsou instructions a znalosti oddělené

Instructions určují, jak se má model chovat.

Znalostní MD obsahuje stabilní kontext projektu: tým, výchozí situaci, dovednosti, rizika, pravidla vyhodnocování a pracovní hypotézy.

Dovednosti týmu jsou uvedeny jako kontext, ne jako závazné budoucí role.
